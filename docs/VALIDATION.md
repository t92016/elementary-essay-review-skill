# 驗收範圍

本機原型曾用直排、多頁及含老師紅筆的小圖測試；公開發行保留相同的原圖座標、候選匯入與資源保護機制，但不公開學生素材。

2026-10-17實測：20項原圖／文件回歸與7項安裝器測試通過；Windows原生x64、Python3.12.13的全新隔離環境完成依賴與官方模型安裝。有上限mobile OCR在合成圖完成4個候選區域，22.11秒、RSS高峰433.9MiB。合成4頁Word及6頁PDF均已預覽。這些不是手寫錯字準確率。

另外已從正式公開HTTPS Pages在第二個新隔離目錄完成完整安裝，不使用GitHub登入；ZIP24檔CRC／SHA、75項Windows依賴、兩個模型雜湊與合成圖片／Word／PDF自測均通過。14個公開文件及程式入口已以HTTP200核對。原本全域技能與工作區本機定稿前後雜湊一致。

完整結果見validation/release-verification.json（Pages副本為validation.json）。安裝器只在配置與合成自測成功後建立全域技能；安裝後仍需Agent實際看圖及用使用者照片驗收。

## 必須分開看的結果

1. 下載與安裝完整性：ZIP／來源雜湊、套件、模型SHA與字型是否可載入。
2. 程式輸出：字框、引文、訂正字、透明層、待確認不畫、多頁與文件是否一致。
3. 實際OCR：固定mobile在有上限程序中完成；候選讀法需看圖核對，完成不是正確率保證。
4. 語意批改：教師逐項核對是否真寫錯、佳句理由與修改是否合宜。
5. 跨機／跨Agent：相同技能格式可以被讀取，不代表所有模型、作業系統已通過端到端驗收。

尚未建立教師獨立確認的真實錯字保留測試集，因此不公布全面錯字準確率、漏判率或誤判率。Core模式不包含已驗證的跨平台OCR保護；非Windows完整OCR仍待適配。純聊天、沒有檔案／Python工具的Agent不能靠讀網址完成本機任務。

如果字型載入但PDF缺字、Word斷頁或圈選偏移，必須修正或標為未完成；不能只以檔案存在宣布成功。既有模型SHA不符時停止，不擅自換新版；OCR失敗保留報告，不無限制重跑server。

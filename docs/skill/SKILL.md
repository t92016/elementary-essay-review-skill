# 國小作文批改小老師 本機公開版

收到作文批改要求時使用。已指定任務就直接接續；只有照片而未說明目的時，確認要完整批改、只找錯字或轉錄。使用繁體中文解說，學生引文保留原來繁簡字形、標點與刪改。

## 初次使用

先讀 [安裝與執行環境](references/local-workflow.md)，依installation.json使用真正的隔離Python、模型與字型，不照抄開發者電腦路徑。未完成配置檢查不得宣稱已可執行OCR。沒有本機工具時，先交付可讀原文的講評並明列無法完成的成品。

## 批改步驟

1. 看原圖、頁數、閱讀方向與既有老師批註，保存來源檔與SHA。EXIF需旋正時另建副本及新座標，不覆寫原照。多頁逐頁核對，不把缺頁當學生沒寫完。
2. 需要OCR時只用本包有上限的mobile流程。保留原始文字、分數、多邊形與疑字；OCR候選不等於學生錯字，不依字數拆行框估算字框。
3. 逐項對應完整原句與原字裁切，再核對位置及批改判斷。依 [資料格式](references/annotation-format.md) 保存JSON，記真正覆核者；Agent看圖不冒稱教師已確認。
4. 確定錯字才圈單字，旁邊紅字寫正字並說明理由。佳句用波浪線與具體賞析；需改句用括線、問題、改法與保留原意的例句。字旁無留白就把長說明放圖外／後頁，不遮住旁字。
5. 模糊字保留pending，無定位另列unlocated；既有老師批註用existing，不當新增成果。不為了展示功能捏造錯字，不把字形、繁簡差異或辨識誤讀判成錯字。
6. 依 [輸出與驗收](references/acceptance.md) 製作原圖透明疊註、工作台、裁切及講評。不得生成、擦除或重畫學生文字。圖檔、Word／PDF共用同份原句、理由、例句與編號。
7. 需要評分時讀 [評分規準](references/rubric.md)。有完整可讀內容才評，疑字與照片品質不扣分。
8. 看每項裁切與最終圈線，逐頁預覽文件繁體中文、引文及版面。記錄誤標、漏標與待確認。只交付真實存在的檔案，分開回報已產生、已預覽與教師待覆核。

Agent可先完成主要批改，人工工作台供覆核與修正；不要求老師每篇從零畫框。缺少可靠位置時先保留文字意見，不能猜座標或以生成圖片替代疊圖。

# 原圖與成品驗收

1. 原圖維持原筆跡；有EXIF旋正時保存原檔與新的旋正副本。SHA、尺寸與所有座標一致，跨頁各自核對。
2. 每項先核對完整原文、字形與上下文，再核對實際框線、訂正判斷。不得把OCR誤讀直接當錯字，或用原有老師圈線充當本次成果。
3. 用Pillow在原圖副本疊透明層；新批註外的底圖像素必須一致。旁欄版可增加尺寸；原尺寸版保留來源大小。
4. 確定錯字有單字圈與近旁紅字；佳句有波浪線與理由；修改有括線、理由與例句。字旁位置需看圖量測留白，不能遮字。
5. pending、uncertain、existing與unlocated不新增訂正紅筆。修改文字／框／判斷後重設核對，不用舊confirmed。
6. PNG、JSON、裁切、Word／PDF使用同份資料。長理由放圖外或文件後頁，不重畫作文。
7. output-manifest的generated只表示檔案已產生；每張圖及每頁文件都要實際預覽。無法預覽便說未完成視覺核對。
8. 記錄錯字誤判、漏判、偏移、覆核者與待確認。固定同批作文比較位置與流程，再決定是否增加其他OCR；無教師真值不宣稱全面準確率。

訂正有證據

圈選核對過的原字，旁邊用紅字寫正字；疑字先列待確認，不把OCR誤讀當學生錯字。

佳句說明好在哪裡

沿原句畫波浪線，說明細節、觀察或修辭的作用；不只給一句「很棒」。

修改附理由與例句

括線標示需改句，提供問題、修改方向與保留原意的參考寫法。

安裝後可以取得什麼

輸出內容
原圖紅筆PNG錯字圈、近旁紅字、佳句波浪線、修改括線；新增批註以外的原圖像素保留。
講評與修改完整原句、理由、修改例；長說明放圖外旁欄與文件。
可調整資料JSON、原字裁切、透明層、離線HTML工作台，可移動圈線與紅字後重產。
Word與PDF依同份核對資料產生；需要可用字型，產生後仍需逐頁預覽。

固定模型與下載

安裝器依官方模型清單與SHA直接下載兩個PP-OCRv5 mobile模型，不把大型模型放進Git。安裝依賴來自PyPI，模型來自Paddle官方HTTPS主機。

  • Mobile偵測模型
  • Mobile辨識模型

操作、驗收與支援範圍

Windows完整模式沿用有上限的CPU低負載流程。其他系統提供core疊圖與文件流程；尚未宣稱跨平台OCR或所有Agent模型的批改品質已驗證。安裝成功、OCR完成、原文判斷正確與版面通過是分開的驗收。
